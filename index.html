fintracker В разработке

Код на GitHub

Backend-сервис финансового трекера: аутентификация, операции с балансом и аналитические запросы. Проект в активной разработке.

От коммита до алерта

  1. git push
  2. lint
  3. test
  4. build
  5. deploy
  6. Kubernetes · Helm
  7. Prometheus · Grafana

  • Архитектура и API

    Три слоя: handler → service → repository. Миграции, индексы под аналитические запросы, эндпоинты описаны в OpenAPI.

  • Безопасность и целостность

    JWT с ротацией refresh-токенов, bcrypt. Операции с балансом атомарны благодаря транзакциям.

  • Производительность

    Кэширование и rate limiting на Redis для аналитических эндпоинтов. Нагрузочное тестирование k6, профилирование pprof.

  • Доставка и мониторинг

    CI/CD на GitHub Actions, деплой на VPS (Nginx, HTTPS) и в Kubernetes через Helm. Prometheus и Grafana с алертами.

Pet-проект · Fullstack (Go + Flutter)/Май 2025 — по настоящее время

Real-time Chat & Task Manager

Код на GitHub

Мессенджер с совместным менеджером задач: backend на Go и кроссплатформенный клиент на Flutter.

Архитектура

  1. Flutter-клиент
  2. REST + WebSocket
  3. Go-сервер
  4. PostgreSQL

  • Real-time backend

    ~20 REST-эндпоинтов и WebSocket-канал: комнаты, онлайн-статус, прочтение, файлы, live-обновления задач.

  • Безопасность

    JWT с refresh-токенами (ротация, отзыв). Найдены и закрыты две IDOR-уязвимости в WebSocket- и REST-эндпоинтах задач.

  • Данные и домен

    Схема PostgreSQL и совместный task-менеджер с двусторонним подтверждением задач.

  • Качество и клиент

    Тесты сервисов, хендлеров и WS-хаба; CI с race-детектором и сканированием зависимостей; Docker (non-root, healthcheck). Flutter-клиент на Riverpod (Windows / Web / Android), 60+ тестов.
